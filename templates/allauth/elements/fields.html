{% load allauth %} {% comment %} Theme override of allauth's generic fields-loop element — see allauth's own allauth/elements/fields.html for the untagged original (just {{ form.as_p }}). Renders each bound field through our styled `field` element instead, so forms built with {% element fields form=form %} (Add Email, Change Password, Reset Password, MFA, …) match the rest of the site instead of falling back to Django's unstyled form.as_p(). {% endcomment %}
